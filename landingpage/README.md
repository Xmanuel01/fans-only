# Landing Page

Landing app for SpicyX, served at `/app/`.

## Commands
- `npm run dev`
- `npm run lint`
- `npm run test`
- `npm run build`

## Route contract
- Brand/home link: `/app/`
- Explore creators: `/user/`
- Become a creator: `/creator/`

## Notes
- Vite base path is `/app/`.
- Production deployment is managed by root-level `vercel.json`.
